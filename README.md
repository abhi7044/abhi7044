## 🧠 About Me

I'm a backend-first full-stack developer who treats the frontend as a tool to make the backend *visible*. I write APIs before I write interfaces, and I started taking system design seriously after realizing there's a huge gap between "it works on localhost" and "it holds up under load." Java DSA isn't just interview prep for me - the way I structure loops and think about complexity directly shapes how I architect Node.js services. I've spent more time than I'd like to admit debugging JWT refresh token logic and Redux state mismatches, but honestly, that's where the real learning happens. Currently a 4th-year IT student at BCET Durgapur, coordinating events at the Robonixx Club and IETE Student ,when I'm not deep in a terminal. My approach to everything: build it, break it, understand why, fix it - whether that's a REST API or a batting lineup.
